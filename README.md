A single-pass CSV reader (`solve.js`) that returns exactly what csv-reader 1.0.0 returns — every column, row and error, byte for byte — while running several times faster, plus the `main.ts` driver that reads `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
